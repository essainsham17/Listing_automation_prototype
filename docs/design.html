04 Technology choices

Selection criteria and rejected alternatives.

AreaChosenWhy over the alternative
Document accessrcloneShips its own pre-approved OAuth app — sidesteps the Azure App Registration wall entirely (§06)
BackendFastAPI + PythonStrongest tooling for vision, PDF rendering and ML. Not the final stack — production is Node.js, and this becomes an internal microservice
FrontendPlain HTML/CSS/JSZero build step. The goal was validating pipeline logic, not building the UI Legend's team owns
Matching modelGroq (gpt-oss-20b)LPU hardware gives real speed independent of pricing tier, unlike free-tier queuing elsewhere
Matching strategyTwo providers, concurrentMeasured: neither is a strict upgrade. Groq better on dense sheets, Gemma on long clean lists. Union-merge checkboxes
Structured outputEnum-constrained schemasPrevents the model inventing a value outside the real options. A hard guarantee, not a hope
Photo sortingYOLOv8, localFree, instant, offline, 100% on real photos. 15 ms against seconds and a per-photo cost
ObservabilityLangfuse + OpenTelemetryLangfuse is itself OTel-based, so FastAPI's instrumentation shares one trace tree — one trace per request, not two systems
OrchestrationLangGraph (not yet live)A library, not infrastructure. Checkpointing suits a multi-minute flow; nodes stay plain testable functions

06 Tried and dropped

Approaches implemented and subsequently removed, with reasons.

  • Azure App RegistrationAbandoned
    ReasonMicrosoft deprecated app registration for accounts without their own Azure AD directory. Errors encountered: AADSTS50020, AADSTS50058.
    Replaced byrclone, which ships a pre-registered OAuth application.
  • Folder-name matchingReplaced
    ReasonLeaf folders are named by colour and VIN, not model number. Folder depth varies by brand.
    Replaced byExact spec-sheet filename search.
  • 24 x rclone catOptimised
    ReasonApproximately 6 minutes per vehicle.
    Replaced byOne batched rclone copy. Approximately 1 minute.
  • onedrive.pyRemoved
    ReasonRequired authentication against a personal Microsoft account from a company device.
    Replaced byLocal folder read, synced by IT-approved means.
  • Single extract + match callSplit
    ReasonCombining extraction and vocabulary matching in one call was unreliable.
    Replaced byTwo separate passes.
  • Per-category bucketsReplaced
    ReasonRequired the model to determine which UI section a feature belongs to before it could be matched.
    Replaced byOne flat vocabulary list.
  • Prose specificationsRejected
    ReasonRemoves structure the matching step requires. Loses precision on rows carrying two values for two trims.
  • Drop strict-schema-firstRejected
    ReasonSaves one call on the current free model, but is the single-call path on any paid model.
  • LLM photo classificationRejected
    ReasonAdds cost and latency to a solved binary classification. The local model is 100% accurate on test photos.
  • filename-parser.jsPorted
    ReasonAuto-fill replaced manual upload; no client-side file remains to parse.
    Replaced byapp/model_code.py, server-side.
  • Dropdown option injectionRemoved
    ReasonAdmin panel lists are closed. Injected options do not exist in the target system.
    Replaced byField left blank and flagged for review.
  • seed_db.pyDeleted
    ReasonTruncated the live database file. Two incidents of data loss.
    Replaced bysample_listings.py, data only.

Orchestration frameworks

Bugs worth remembering

Defect: output truncation misreported as invalid JSON

Symptom: extraction failed with invalid JSON; the error text attributed this to provider instability and recommended a retry.

Cause: the response was truncated at the output token limit. completion=7996 against an 8000 cap; previously completion=3996 against 4000. The limit had been raised once before for the same reason.

Contributing factor: the stop reason was returned by the API but not evaluated. Retrying could not succeed, as the failure is deterministic.

Resolution: truncation is now detected, the response repaired where possible, and the gap recorded in low_confidence_fields.
